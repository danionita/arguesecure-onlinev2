# History and versions

Every change to an assessment is recorded. Open **History** from the bar
above any view to see them.

## Versions

A **version** is a saved copy of the whole assessment — its structure, its
values and the totals they produced. The History page is a list of them,
newest first:

- **Current version**, at the top, holds every change made since the last
  save. **Save as version** saves it now, with an optional name — before a
  workshop, say, or before a big restructure.
- Versions are also **saved automatically**: after 30 minutes without
  edits, or after 50 changes. An assessment nobody has touched gets none.
- Each saved version says who or what saved it and lists the changes that
  went into it.

For any saved version you can:

- **View** it — the chart and list as they were, read-only.
- **Compare** it with the version before it.
- See its **Figures** — the totals as they stood.
- **Restore** it. Restoring first saves the current state as a safety copy,
  so a restore can itself be undone by restoring that copy.

Anyone who can view an assessment can read its history. Saving, restoring and
deleting versions need edit access.

## Smaller undo

- `Ctrl`/`Cmd` `+Z` undoes the last structural change — adding, deleting,
  moving or linking a node — even one made by someone else, after asking.
- A single field edit is reverted from the **History** tab of that node's
  pop-up.

## Deleted assessments

A deleted assessment moves to **Deleted**, at the bottom of **My assessments**,
and is erased for good after 30 days (your administrator may set another
period); each row shows the date. Until then:

- **Restore** brings it back as it was. The owner, a manager or an
  administrator can restore it.
- **Erase permanently** removes it now, with its history, versions, comments
  and notifications. Only the owner or an administrator can; it cannot be
  undone.

Versions protect against mistakes made inside ArgueSecure. They are not a
backup of the server; that is the administrator's job.
