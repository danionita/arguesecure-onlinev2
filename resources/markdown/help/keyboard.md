# Keyboard map

An assessment can be built from the keyboard — a facilitator typing during a
workshop can't always reach for a mouse. Press **`?`** in an assessment to
show this map without leaving the page.

| Key | Action |
|---|---|
| `↑` `↓` | Move focus between visible nodes |
| `←` `→` | Collapse / expand the focused node, or move to its parent / first child |
| `Enter` | Add a sibling of the focused node |
| `Tab` | Add a child of the focused node |
| `Space` or `F2` | Open the focused node's pop-up |
| `Escape` | Close the pop-up, or clear focus |
| `Delete` / `Backspace` | Delete the focused node |
| `Ctrl`/`Cmd` `+Z` | Undo |
| `Shift+Ctrl`/`Cmd` `+Z` | Redo |
| `/` | Focus the search box |
| `Ctrl`/`Cmd` `+` / `−` / `0` | Zoom in / out / reset |
| `?` | Show this map |

`Enter` and `Tab` open the new-node pop-up with its title field focused:
type the name and press `Enter` to add it, or `Escape` to leave without
adding anything.

These keys act on the focused node only. Inside a text field or a pop-up,
`Tab`, `Enter` and the arrows do what they normally do.

## Before you rely on it

**`Delete` does not ask for confirmation**, even when the node has children.
Press `Ctrl`/`Cmd` `+Z` straight away to undo a delete you didn't mean.

There is no command palette (`Ctrl`/`Cmd` `+K`) and no `Shift+Tab` to
promote a node: a node's level is its type, so moving an attack under
another risk is done by dragging it.
