# Templates

A template is an assessment set aside as a starting point. **Templates** in
the sidebar lists them, and using one creates a copy you own. The template
itself never changes.

Every account can use templates. Only administrators manage them on the Templates page
(**New template**, **Edit**, **Delete**), or by choosing **Publish as template**
in an assessment's **Share** dialog, which adds an unlinked copy; a template is
removed only by deleting it.

## The bundled templates

- **Northwind Outfitters** — a demo web shop, part-way through an assessment.
- **Four system archetypes** — a public web application, a multi-tenant
  SaaS, a corporate internal network and a connected home device.
- **Nine standards** — ISO/IEC 27001:2022, ISO/IEC 42001:2023, the EU AI
  Act, SOC 2, GDPR, NIS2, the CIS Controls v8.1, the NIST Cybersecurity
  Framework 2.0 and the EU Cyber Resilience Act.

The standards templates are gap-analysis starting points: every control or
obligation is a defence set to *todo*, under the threats it addresses. Mark
what you already have as implemented, shelve what is out of scope, and give
the risks and attacks values for your own system. Descriptions summarise the
controls; they are not the text of the standard, and not legal advice.

Each of those defences cites its control on the **References** tab
(`ISO27001-2022:A.5.23`), and the report's **Control coverage** groups by
it. On a defence of your own, choose **Control** and type a framework code
(`ISO27001-2022`, `ISO42001-2023`, `EUAIACT`, `GDPR`, `NIS2`, `SOC2`,
`CIS8`, `CSF2`, `CRA`), a colon and the control. **Add from template** copies titles, not
citations.

## Taking parts of a template

You don't have to start from a template to use one:

- **Add from template** on a card adds any number of a template's risks,
  attacks or defences under that node.
- **From template** in the new-node pop-up fills in one.

Only titles and descriptions (and whether a defence is a transfer) are
copied — never values. A node whose title already exists in your assessment
is linked rather than copied twice. See [Building an
assessment](/help/building).
